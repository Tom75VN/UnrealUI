## UnrealUI 0.11.0

* Pet interface improved
* Nameplate features:
   * The nameplate color is now based on the unit reaction (Hostil / Neutral / Friendly)
   * New Nameplates settings: General, Health, Target, Raid Marks pages
   * Every option works in every theme
   * Width, height, vertical offset sliders
   * Name and health-text font sizes
   * Show hostile / friendly plates
   * Health text: format, position, number abbreviation
   * Hide health bars by unit type
   * Keep health on target / damaged units
   * Fade opacity for non-targets
   * Target zoom
   * Target outline with custom colour
   * Reaction outlines
   * Raid marks: position, size, offset
   * Long name abbreviation
   * Target plate drawn above others
   * Combo points on target plate
   * Class-coloured player bars and names
   * Guild name line (own guild green)
   * Totems: hide health or show icon
   * Hide health on critters
   * Party, raid and guild members show as friendly
   * Modern WoW: names now shown
