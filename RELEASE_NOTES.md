## UnrealUI 0.0.4

- Fixed incorrect keybind mappings that could activate slots from a different action bar.
- Added visual highlighting to the correct action bar slot when its keybind is pressed.
- Optimized party frames.
- Fixed Rogue stealth bar paging; Bar 7 is now locked for Rogues.
- Added a setting to show or hide the minimap settings button.
- Added a configurable pet action bar (more tests needed).
- Improved debuff management in the unit-frame settings.
- Improved the settings menu.
- Added the minimap as an anchor in the Mover UI.
